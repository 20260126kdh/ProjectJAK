# 작살잡이 게임 디자인

## 한 줄 소개

작살과 선원 소환을 핵심 전투 자원으로 사용하는 2D 덱 빌딩 로그라이크.

## 현재 코드에서 확인되는 플레이 흐름

1. 타이틀에서 새 게임 또는 이어하기를 선택한다.
2. 클래스를 선택하고 시작 덱을 구성 또는 확인한다.
3. 일반 전투를 진행한다.
4. 보상과 휴식 단계를 거친다.
5. 스테이지 보스 전투를 진행한다.

## 핵심 시스템

### 전투 SFX

- 플레이어와 선원의 공격은 `attack` 이후 0.1초 뒤 피격 판정음을 재생한다.
- 방어도가 공격 전체를 흡수하면 `blocked_hit`을 사용한다.
- 방어도를 관통하면 실제 체력 피해가 20 미만일 때 `hit ver.1`, 20 이상일 때 `hit ver.2`를 사용한다.
- 선원의 공격과 선원 피격은 피해량과 관계없이 `hit ver.1`을 사용한다.
- 작살 스택을 가진 적이 관통 피해를 받으면 일반 피격음 대신 `harpoonstack_hit`을 사용한다.
- 중독과 자해처럼 공격 행동이 아닌 체력 감소에는 공격 SFX를 사용하지 않는다.
- 한 카드의 복합 효과음은 공격/피격 → 방어도 → 버프 → 디버프 → 작살 스택 순서로 재생한다.
- 각 카테고리 시작 간격은 공격 0.3초, 방어도 0.6초, 버프 0.6초, 디버프 0.7초다.
- 서로 다른 버프 또는 디버프가 동시에 2종 이상 적용되면 해당 효과음을 0.2초 간격으로 최대 2회 재생한다.
- 동일 상태를 여러 대상에게 부여한 것은 한 종류로 계산하며 `Exit`은 버프음 대상에서 제외한다.
- 실제 손패로 이동하는 카드마다 드로우음을 한 번 재생하고 카드에 마우스가 진입할 때 Hover음을 재생한다.
- 휴식 회복과 강화 패널 진입에는 각각 전용 효과음을 사용하며 전투 후 자동 회복에는 회복음을 사용하지 않는다.
- 마지막 적 처치 후 보상 패널이 표시되는 순간 승리음을 재생한다.
- 마우스 또는 키보드 입력이 시작된 프레임에는 공통 클릭음을 한 번 재생한다.
- 적의 성공한 패턴 행동도 공격/피격 → 방어도 → 버프 → 디버프 순서로 효과음을 재생한다.
- 적의 독오름, 불어터진 피부, 모독받은 후광과 심해의 속삭임으로 상태이상이 실제 부여될 때 디버프음을 재생한다.

### 카드 전투

- 카드는 피해, 방어도, 회복, 체력 소모, 드로우, 상태 효과, 작살, 조건부 효과와 소환 효과를 실행할 수 있다.
- 공격과 자신 대상 흡혈 효과가 한 카드에 함께 있으면 그 카드가 실제로 입힌 피해만큼 즉시 회복하고 흡혈 상태를 남기지 않는다.
- 대상은 자신, 단일 적, 전체, 전체 적, 무작위 적, 언데드 계열로 구분된다.
- 카드 강화 상태가 존재하며 표시 이름에 `+`가 붙는다.

### 작살

- 적에게 작살을 적용하고 작살 스택을 참조하는 카드 효과가 존재한다.
- 작살의 정확한 획득·소모·최대치와 전투 종료 처리 규칙은 기획 확인이 필요하다.

### 소환

- 플레이어는 전투 중 선원(Crew)을 소환할 수 있다.
- 소환 유닛은 체력을 가지며 단일/전체 공격, 회복, 희생 관련 카드 효과와 상호작용한다.
- 기본 코드 설정상 동시에 최대 3명을 관리하지만 최종 값은 Inspector 설정을 따른다.

### 상태 효과

- 강화, 약화, 방어 제한, 중독, 마비, 불사, 언데드 등 여러 상태가 존재한다.
- 플레이어와 적이 같은 상태 효과 처리 기반을 공유한다.
- 개별 상태의 정확한 수치 계산식과 중첩 규칙은 `StatusEffectHandler` 및 각 실행 로직을 기준으로 한다.

### 적과 Intent

- 적 행동은 CSV 기반 턴 패턴과 조건으로 구성된다.
- 한 턴에 여러 행동을 순서대로 실행할 수 있다.
- 다음 행동은 Intent UI와 아이콘 데이터베이스를 통해 예고한다.

### 진행과 이어하기

- 진행 상태, 플레이어 체력, 클래스, 덱과 카드 강화, 스테이지/보스 정보를 저장한다.
- 이어하기 시 저장한 전투의 시작 상태와 카드 순서를 복원하여 해당 전투를 처음부터 다시 시작한다.

## 기획 문서화 대기 항목

- 세계관, 캐릭터와 클래스별 정체성
- 승리/패배 및 전체 런 종료 조건
- 스테이지 수와 각 스테이지 구성
- 카드 획득, 제거, 강화 경제
- 작살 시스템의 공식 규칙
- 모든 상태 효과의 플레이어용 설명
- 적/보스 목록과 패턴 설계 의도
- 보상, 휴식, 계시(HRevelation) 시스템 규칙

확정되는 항목은 날짜와 결정 배경을 함께 이 문서에 추가한다.
