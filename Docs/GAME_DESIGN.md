# 작살잡이 게임 디자인

## 한 줄 소개

작살과 선원 소환을 핵심 전투 자원으로 사용하는 2D 덱 빌딩 로그라이크.

## 현재 코드에서 확인되는 플레이 흐름

1. 타이틀에서 새 게임 또는 이어하기를 선택한다.
2. 클래스를 선택하고 시작 덱을 구성 또는 확인한다.
3. 일반 전투를 진행한다.
4. 보상과 휴식 단계를 거친다.
5. 스테이지 보스 전투를 진행한다.

## 핵심 시스템

### 전투 SFX

- 플레이어와 선원의 공격은 `attack` 이후 0.1초 뒤 피격 판정음을 재생한다.
- 공격으로 방어도가 정확히 0이 되더라도 실제 HP 피해가 없으면 `blocked_hit`을 사용한다.
- 방어도가 0이 된 뒤 실제 HP 피해가 발생하기 시작한 공격부터 피해가 20 미만일 때 `hit ver.1`, 20 이상일 때 `hit ver.2`를 사용한다.
- 선원의 공격과 선원 피격은 피해량과 관계없이 `hit ver.1`을 사용한다.
- 작살 스택을 가진 적도 방어도 소진 여부가 아니라 실제 HP 피해가 발생한 공격부터 일반 피격음 대신 `harpoonstack_hit`을 사용한다.
- 중독과 자해처럼 공격 행동이 아닌 체력 감소에는 공격 SFX를 사용하지 않는다.
- 한 카드의 복합 효과음은 공격/피격 → 방어도 → 버프 → 디버프 → 작살 스택 순서로 재생한다.
- 각 카테고리 시작 간격은 공격 0.3초, 방어도 0.6초, 버프 0.6초, 디버프 0.7초다.
- 서로 다른 버프 또는 디버프가 동시에 2종 이상 적용되면 해당 효과음을 0.2초 간격으로 최대 2회 재생한다.
- 동일 상태를 여러 대상에게 부여한 것은 한 종류로 계산하며 `Exit`은 버프음 대상에서 제외한다.
- 실제 손패로 이동하는 카드마다 드로우음을 한 번 재생하고 카드에 마우스가 진입할 때 Hover음을 재생한다.
- 휴식 회복과 강화 패널 진입에는 각각 전용 효과음을 사용하며 전투 후 자동 회복에는 회복음을 사용하지 않는다.
- 마지막 적 처치 후 보상 패널이 표시되는 순간 승리음을 재생한다.
- 마우스 또는 키보드 입력이 시작된 프레임에는 공통 클릭음을 한 번 재생한다.
- 적의 성공한 패턴 행동도 공격/피격 → 방어도 → 버프 → 디버프 순서로 효과음을 재생한다.
- 적의 독오름, 불어터진 피부, 모독받은 후광과 심해의 속삭임으로 상태이상이 실제 부여될 때 디버프음을 재생한다.

### 카드 전투

- 카드는 피해, 방어도, 회복, 체력 소모, 드로우, 상태 효과, 작살, 조건부 효과와 소환 효과를 실행할 수 있다.
- 테크니션 시작 스킬 `엄폐`는 방어도 12와 단일 적 작살 3을 부여한다.
- 캡틴 시작 스킬 `길잡이`는 모든 적에게 피해 10과 약화·취약 1을 부여한다.
- 공격과 자신 대상 흡혈 효과가 한 카드에 함께 있으면 그 카드가 실제로 입힌 피해만큼 즉시 회복하고 흡혈 상태를 남기지 않는다.
- `악마와의 거래`는 강화 시 체력 손실과 영구 힘 획득이 각각 5에서 7로 증가한다.
- 대상은 자신, 단일 적, 전체, 전체 적, 무작위 적, 언데드 계열로 구분된다.
- 카드 강화 상태가 존재하며 표시 이름에 `+`가 붙는다.

### 작살

- 적에게 작살을 적용하고 작살 스택을 참조하는 카드 효과가 존재한다.
- 작살의 정확한 획득·소모·최대치와 전투 종료 처리 규칙은 기획 확인이 필요하다.

### 소환

- 플레이어는 전투 중 선원(Crew)을 소환할 수 있다.
- 소환 유닛은 체력을 가지며 단일/전체 공격, 회복, 희생 관련 카드 효과와 상호작용한다.
- 기본 코드 설정상 동시에 최대 3명을 관리하지만 최종 값은 Inspector 설정을 따른다.

### 상태 효과

- 강화, 약화, 방어 제한, 중독, 마비, 불사, 언데드 등 여러 상태가 존재한다.
- 상태 효과 enum은 카드와 아이콘의 Unity 직렬화 호환성을 위해 각 숫자 값을 명시적으로 유지한다.
- 플레이어와 적이 같은 상태 효과 처리 기반을 공유한다.
- 개별 상태의 정확한 수치 계산식과 중첩 규칙은 `StatusEffectHandler` 및 각 실행 로직을 기준으로 한다.
- 여러 적이 플레이어에게 같은 지속형 디버프를 부여하면 최초 수치는 유지하고 각 효과의 지속 턴을 합산한다.
- 중독과 영구 효과는 적 디버프 지속 턴 합산에서 제외하고 기존 중첩 규칙을 유지한다.

### 적과 Intent

- 적 행동은 CSV 기반 턴 패턴과 조건으로 구성된다.
- 한 턴에 여러 행동을 순서대로 실행할 수 있다.
- 다음 행동은 Intent UI와 아이콘 데이터베이스를 통해 예고한다.

### 진행과 이어하기

- 진행 상태, 플레이어 체력, 클래스, 덱과 카드 강화, 스테이지/보스 정보를 저장한다.
- 이어하기 시 저장한 전투의 시작 상태와 카드 순서를 복원하여 해당 전투를 처음부터 다시 시작한다.

## 기획 문서화 대기 항목

- 세계관, 캐릭터와 클래스별 정체성
- 승리/패배 및 전체 런 종료 조건
- 스테이지 수와 각 스테이지 구성
- 카드 획득, 제거, 강화 경제
- 작살 시스템의 공식 규칙
- 모든 상태 효과의 플레이어용 설명
- 적/보스 목록과 패턴 설계 의도
- 보상, 휴식, 계시(HRevelation) 시스템 규칙

확정되는 항목은 날짜와 결정 배경을 함께 이 문서에 추가한다.
# 첫 전투 튜토리얼

- 새 게임에서 시작 덱 확인을 마친 뒤 선택한 클래스에 맞는 튜토리얼을 시작한다.
- 이어하기로 복원한 전투에서는 튜토리얼을 다시 시작하지 않는다.
- 대화 출력 중에는 배경을 검은색 40%로 암전하고 튜토리얼 UI 외 입력을 차단한다.
- 튜토리얼은 클래스별 초상화와 대사를 사용하되, 공격·방어·스킬·작살·보존의 실제 행동 흐름은 공통 규칙으로 진행한다.
- 튜토리얼 첫 손패는 투창, 회피, 선택 클래스의 시작 스킬 카드 2장을 각각 한 장씩 사용한다.
- 첫 손패에서 제외된 시작 덱 카드 6장은 무작위로 섞여 드로우 파일에 남는다.
- 튜토리얼 카드 행동은 투창, 회피, 클래스별 첫 번째 스킬 순서로 진행한다.
- 행동 대기 중 지정 카드만 선택·사용할 수 있으며 빨간 테두리를 1초 간격으로 점멸한다.
- 튜토리얼 진행 중 턴 종료, 보존, 덱 보기, 전투 건너뛰기와 퍼즈 입력은 차단한다.
- 첫 번째 클래스 스킬 사용 뒤에는 두 번째 클래스 스킬만 보존할 수 있도록 안내한다.
- 지정 카드 보존 확정 뒤 기존 적 턴과 다음 턴 드로우를 진행한다.
- 다음 플레이어 턴에 클래스별 일반 초상화와 변화 초상화의 마무리 대사를 표시한 뒤 튜토리얼을 종료한다.
- 튜토리얼 대사는 다음 버튼 또는 스페이스바로 한 단계씩 진행한다.
- 지정 카드를 선택하면 실제 적용 대상 머리 위에 빨간 역삼각형을 표시한다.
- 보존 안내는 턴 종료/보존 진입, 지정 카드 선택, 보존 확정 순서로 진행한다.
# 휴식 이미지 연출 규칙

- 휴식 단계에서는 전투 손패의 표시를 비활성화하고 다음 전투 시작 직전에 복구한다.
- 휴식 버튼 화면은 현재 직업의 `*_Rest` 이미지로 전투 UI와 핸드를 가린다.
- Rest와 Upgrade 라벨은 버튼 이미지 아래에 표시한다.
- 휴식 단계 시작 화면부터 현재 직업의 전용 이미지를 배경으로 표시한다.
- Rest 버튼을 누르면 모든 휴식 버튼을 숨기고 현재 직업의 `CAP_Rest`, `PHY_Rest`, `TEC_Rest` 이미지를 표시한다.
- 1초 후 검은 화면으로 0.3초 페이드 아웃하고 해당 직업의 `*_Rest_End` 이미지로 교체한 뒤 0.3초 페이드 인한다.
- 페이드 인 완료 후 0.5초 뒤 사용 가능한 버튼을 다시 표시한다.
- 카드 강화와 강화 취소는 휴식 이미지 연출을 실행하지 않는다.
- Rest와 Upgrade 버튼은 화면 중앙보다 아래쪽에 배치한다.
# 턴 전환 배너 규칙

- 적 턴 시작에는 `적 턴`, 플레이어 턴 시작에는 `내 턴` 두루마리 배너를 화면 중앙에 표시한다.
- 배너는 좌측에서 우측으로 0.4초 동안 펼치고 0.5초 유지한 뒤 0.4초 동안 접는다.
- 적 행동은 적 턴 배너가 종료된 뒤 시작하며, 배너 재생 중에는 플레이어 전투 입력을 차단한다.
# 카드 클릭 대상 규칙

- 카드의 모든 효과 중 Enemy, AllEnemies, RandomEnemy가 하나라도 있으면 적을 클릭해 사용한다.
- 적 대상 효과와 Self 효과가 함께 있는 혼합 카드는 적 클릭을 우선한다.
- Self 및 직접 선택이 필요 없는 전체 선원 효과만 있는 카드는 플레이어를 클릭해 사용한다.
- 선원 한 명을 직접 희생하는 카드는 해당 선원을 클릭해 사용한다.
- 잘못된 대상을 클릭하면 카드 효과, 카드 소모, 사용 횟수와 보유 상태 효과 소모를 모두 실행하지 않는다.
# 사망 UI 이미지 규칙 (2026-08-18)

- 사망 UI는 상단 사망 문구, 최종 진행 스테이지, 중앙 하단 타이틀 복귀 버튼 순으로 배치한다.
- 플레이어 사망 이미지는 화면 왼쪽 아래에 표시한다.
- 클래스별 플레이어 Prefab의 `PlayerCombat > Death Transition Settings > Death Character Sprite`에 해당 이미지를 연결한다.
- 사망 이미지가 연결되지 않은 경우 캐릭터 이미지만 생략하고 나머지 사망 UI는 정상 표시한다.
- 사망 문구와 최종 진행 스테이지는 공통 `Death_UI.png` 금속 프레임을 사용한다.
- 프레임 내부 문구는 밝은 아이보리색과 검은 외곽선을 사용한다.
- 사망 작살은 화면을 관통하지 않고 플레이어 위치에 꽂힌 채 잠시 정지한다.
- 사망 작살은 화면 우측 위에서 플레이어 방향으로 회전한 상태로 진입한다.
- 작살 충돌 지점에서 붉은 원이 확산되어 화면 전체를 덮은 뒤 사망 UI를 표시한다.
- 붉은 원형 확산 시간은 0.68초를 기준으로 한다.
- 사망 작살에는 각 클래스 공격 Atlas의 원본 궤적과 충돌 섬광을 사용한다.
- CAP는 보라색, PHY는 붉은색, TEC는 초록색 효과를 사용한다.
- 작살과 비행 꼬리는 충돌 후 0.12초 동안 빠르게 사라진다.
- 충돌 섬광은 작살촉에서 화면 아래 방향으로 55px 보정하며 붉은 확산도 같은 위치에서 시작한다.
- 타이틀 복귀 버튼은 메인 타이틀의 게임 시작 버튼 Normal/Hover/Pressed 이미지를 공통 사용한다.
# 게임 클리어 엔딩

- Stage 3 최종 보스 아리엘 처치 시 보상 화면을 표시하지 않고 `GameClearScene`으로 이동한다.
- 게임 클리어 씬에서는 전투 BGM을 정지하고 `Ending.mp4`를 전체 화면으로 한 번 재생한다.
- 엔딩 영상 재생이 끝나면 페이드 전환으로 `Main_TitleScene`에 복귀한다.
- 엔딩 영상에는 오디오 트랙이 없으며 무음으로 재생한다.
